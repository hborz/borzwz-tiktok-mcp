Privacy Policy

Last updated: September 9, 2026

BORZWZ TikTok MCP is a private developer tool designed to connect a TikTok account, with the account owner's explicit authorization, to an AI assistant for profile and video analytics.

Data accessed

The application may access only the TikTok data authorized through TikTok OAuth and the scopes enabled for the app, such as basic profile information, profile details, account statistics, and public video information.

How data is used

Authorized TikTok data is used only to provide the requested functionality, including displaying profile information, retrieving public videos, and analyzing content performance. The application does not sell personal data or use it for advertising.

Authentication

The application uses TikTok's official OAuth authorization flow. TikTok credentials and authorization tokens are not intended to be exposed publicly. The user can revoke the application's access from their TikTok account settings.

Data storage

The project is intended primarily for private use. Any locally stored tokens or cached data are used only for operating the integration and should be kept on the user's own device or controlled environment. No public database of TikTok user data is maintained by this project.

Third parties

The application relies on TikTok's official developer APIs. When AI-assisted analysis is requested, relevant authorized data may be processed by the AI service used by the account owner for that request.

Data deletion

The account owner can stop using the application, revoke TikTok authorization, and delete any locally stored application data at any time.

Changes

This policy may be updated if the functionality of the project changes. The current version will remain available on this page.

Contact

For questions about this project or this privacy policy, use the repository owner's GitHub contact channel.
