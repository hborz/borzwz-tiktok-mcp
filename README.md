# BORZWZ TikTok MCP — Public Legal Pages

This repository contains only the public pages required for the BORZWZ TikTok MCP developer integration.

## Public pages

- `index.html` — project information
- `privacy.html` — privacy policy
- `terms.html` — terms of service

## Security

No TikTok client secret, OAuth access token, refresh token, API key, `.env` file, private account data, or MCP backend code belongs in this repository.

The actual MCP backend and credentials must remain in a separate private repository or local environment.

## GitHub Pages

The site is intended to be published from the `main` branch at the repository root using GitHub Pages.
